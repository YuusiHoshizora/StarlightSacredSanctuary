# 警报等级
|      等级       |               应用场景               |    授权等级     |                                  说明                                   |
| :-----------: | :------------------------------: | :---------: | :-------------------------------------------------------------------: |
| LEVEL 1<br>蓝色 |     对个人生活会造成影响的事件，对星光圣域总体无影响     | 星光圣域预备成员及以上 |       此等级警报的处理顺序较低，如非必要请不要使用该警报。但是，此警报的误报影响较低，当难以决定异常情况时，请使用此等级       |
| LEVEL 2<br>青色 | 对个人生活会造成严重影响的事件，对部分小型组织可能会造成明显影响 | 星光圣域预备成员及以上 |  此等级警报的处理顺序较低，但这也是星辰护卫队最优先处理的警报。若是星辰护卫队无法处理LEVEL 1和LEVEL 2警报的话，请马上上报  |
| LEVEL 3<br>绿色 | 对星光圣域的非官方组织造成明显影响的事件，可能导致部分区域动荡  | 星光圣域正式成员及以上 |              此等级警报的处理顺序中等，同时相关的星光圣域部门将会收到该事件的有关情报并执行对应方案              |
| LEVEL 4<br>黄色 |  对星光圣域的官方组织造成明显影响的事件，可能导致部分舰船动荡  | 星光圣域正式成员及以上 |                 此等级警报的处理顺序较高，此时视情况星辰护卫队有权宣布戒严并使用致命武器                  |
| LEVEL 5<br>橙色 |    对星光圣域造成整体影响的事件，部分舰队可能会出现损伤    | 星光圣域高级成员及以上 |          此等级警报的处理顺序极高，此时星辰护卫队应当宣布戒严并使用致命武器，星辰突击队将接替关键节点的保卫工作          |
| LEVEL 6<br>红色 |    对星光圣域造成显著影响的事件，可能导致大量的人员伤亡    | 星光圣域高级成员及以上 |            此等级警报的出现说明星光圣域正在与敌对势力交战，请注意保护个人的安全并尽快停止附近的危险设施             |
| LEVEL 7<br>紫色 |    对星光圣域造成极其显著的事件，将会导致大量的人员伤亡    | 星光圣域管理成员及以上 |        此等级警报的出现说明星光圣域已经遭到了敌对势力的直接进攻，如无必要，切勿离开重型装甲保护区，并做好个人的保护         |
| SPECIAL<br>黑色 |          舰船失去与星光圣域的一切联系          | 星光圣域正式成员及以上 |               此等级仅供舰船的舰长使用，并将在与星光圣域恢复联系后自动解除；警报等级交由舰长决定               |
| SPECIAL<br>灰色 |          舰船进入非星光圣域势力范围           | 星光圣域正式成员及以上 |              此等级仅供舰船的舰长使用，并将在进入星光圣域势力范围后自动解除；警报等级交由舰长决定               |
| SPECIAL<br>白色 |           舰船进入超光速航行状态            | 星光圣域正式成员及以上 | 此等级仅供（分）舰队指挥官使用，在准备超光速航行时自动启用，并在解除超光速航行时自动解除；启用后在1个周期内未开始准备超光速航行时自动解除 |
| SPECIAL<br>无色 |              教学、测试               |   友善人员及以上   |                           此警报等级为空闲等级，没有任何效果                           |
# 研究等级
| 等级  | 代号  |           授权等级            |     说明      |         举例         |
| :-: | :-: | :-----------------------: | :---------: | :----------------: |
| 普通  |  N  |        星光圣域预备成员及以上        | 此等级供一般研究使用  |  个人研究、民用设备<br>研究   |
| 高级  |  U  |        星光圣域高级成员及以上        | 此等级供高级等级使用  |        高级研究        |
| 军事  |  A  |        星光圣域正式成员及以上        | 此等级仅供军事研究使用 |      战舰配件研究等       |
| 机密  |  S  |        星光圣域高级成员及以上        | 此等级仅供机密研究使用 |        N/A         |
| 考核  |  C  | 星光圣域预备成员及以上<br>星光圣域管理成员以下 |  此等级仅供考核使用  | 星光圣域授权等级<br>提升考核研究 |
# 事故等级
| 等级  | 归档需要  | 代号  |              说明              |
| :-: | :---: | :-: | :--------------------------: |
| 微小  |   否   |  C  |      此等级用于那些未造成直接损伤的事故       |
| 小型  |   否   |  X  | 此等级用于那些造成设备可维修损坏，未造成人员损伤的事故  |
| 中型  | 视情况而定 |  M  |    此等级用于那些造成设备损坏或人员损伤的事故     |
| 大型  |   是   |  L  | 此等级用于那些造成大规模设备不可维修损坏或人员死亡的事故 |
| 重大  |   是   |  H  |      此等级仅供失败的星光圣域官方实验使用      |
