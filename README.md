# 星光圣域 · Starlight Sacred Sanctuary

**线上站点：<https://starlightsacredsanctuary.top>，<https://stsas/top>**

一个个人架空世界的展示站点。世界的地图、势力、事件与设定都写在站点里，
这个仓库只是那些页面的源码 —— 设定内容不在这里重复。

## 第一次来，从哪儿看起

打开站点首页，点 **ENTER** 进入主页面 —— 那是这个世界的入口，按时间倒序排着所有已发布的事件。
点任意一张卡片展开全文；左侧可以按分类筛选：
**重要通知** / **本地日志** / **观测报告** / **技术文档** / **航行手记**。

## 站里有什么

| 想看什么 | 去哪一页 |
| --- | --- |
| 这个世界发生了什么 | **主页面** —— 事件列表，点卡片读全文，左侧按分类筛 |
| 世界有多大、有哪些星系 | **星图** —— 34 个星系，可缩放，可按中文名或英文名搜索，右侧显示单个星系的资料 |
| 有哪些势力与舰队 | **舰队** —— 科研与管理 / 工业与收集 / 主防御 |
| 设定资料 | **档案** —— 人员、舰队、研究、组织、文件、装备、生物等分类。**目前还是空架子**，卡片点进去没有内容 |
| 顺手的小工具 | **工具** —— 拾色器、以及星纪元 ⇄ 公元的时间转换 |

## 一点设定上的提示

- 站内有两套历法：**星纪元（S.E.）** 与 **公元（A.D.）**。事件用公元标日期；
  想知道某个日子在星纪元是哪一天，用工具页的「时间转换」互转

## 技术上的事（给同好）

纯静态站点：没有框架、没有构建步骤、没有依赖 —— 仓库根目录就是网站根目录，
部署也只是把这个目录原样交给静态托管，没有构建产物。

- 背景与星图都是 Canvas 手绘的（星野、六边形网格、鼠标附近的激活区）
- 事件正文是 Markdown，在浏览器端用 marked 渲染
- 有一个 Service Worker：访问过一次之后，断网也能打开站内页面；页面之间的跳转带淡入淡出
- 手机 / 平板等窄屏上，每一页都有单独的排版
