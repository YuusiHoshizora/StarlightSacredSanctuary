# 星光圣域 · 设计语言（统一版 v6）

> 本文是**全站唯一的设计语言规范**。`docs/DESIGN.md` 保留交互、加载屏、指针与踩坑记录，
> 颜色 / 字体 / 层级 / 组件规则以本文与 `assets/css/tokens.css` 为准。
> 一句话：**紫金仪器**——以圣域紫 `#3A3072` 为氛围、基本色银 `#C0C0C0` 为结构、
> 高亮金 `#FFD700` 为"点亮"，用等宽读数与宽字距建立"精密仪器"的秩序；
> 所有页面（含加载屏、404、目录页）共用同一套令牌。
>
> **v3 相对 v2 是一次"定色"**：v2 里那抹深靛蓝（`#264270`）与冰蓝结构线（`#8AD6E8`）
> 全部退役，改为世界观权威色板；同时把圆角、动效、渐变三项做了复核（结论见 §4、§5）。
>
> **v4 是一次"状态与秩序"修正**：目录状态条不再显示已记录数量；面包屑各层位置与字体
> 恒定、当前层只加粗；文件档案去掉了「卡片套卡片」；滚动渐隐遮罩全部移除；
> **v5 再收一层**：页头只留英文标识（删掉 `// 04` 与状态尾注），世界观的离线标识不
> 到处张贴（星图自己显示 Offline Mode），缺失数据统一用「数据损坏」措辞。
> **v6 是扁平化**：卡片 / 面板改为半透明平涂，不再用玻璃渐变、顶部高光、投影；
> 模糊统一 2px、圆角统一 12px（控件 3px），可点卡片 hover 不位移、不投影。
> **v7**：全站移除目录 `CATALOG` 状态条与数量读数——目录不再报状态；
> 只有未归类档案保留一张可选占位卡。

## 一、定位与气质

世界观是"星光圣域：深空、寂静、精密仪器"。设计语言的目标不是"炫技科幻"，而是
**一台长期值守的深空观测终端**：

| 要 | 不要 |
| --- | --- |
| 由圣域紫推导的墨色（紫墨、紫雾） | 纯黑 + 紫色霓虹、彩虹渐变 |
| 1px 结构线、刻度、角标、读数 | 大面积发光、毛玻璃彩虹、投影糊脸 |
| 金色只标记"被点亮 / 已收录 / 关键读数" | 每个标题都涂金（金色通胀后不再有强调力） |
| 等宽拉丁小标签（`ARCHIVE // 04`） | 花体、装饰字体、描边伪粗体 |
| 克制动效：淡入、位移 ≤ 8px、140–420ms | 弹跳、过冲回弹、旋转卡片、视差大位移 |

**统一性的三条硬规则**

1. 颜色、字号、字距、间距、圆角、过渡**一律取令牌**（`assets/css/tokens.css`），页面样式表只负责布局。
2. 每个页面都有同一套"页头语法"：眉标 → 中文标题 → 等宽英文副题 → 一行导语。
3. 加载屏与正文是同一台机器：同一墨色、同一高亮金、同一银结构线、同一套字体层级。

**v3 的配色纪律（比 v2 更硬）**

> **紫 = 氛围，银 = 结构，金 = 点亮。** 三者分工固定，页面不得混用：
>
> - **紫**（`--tone` 家族）只进氛围层：星野底色、极光、激活区、选区、顶栏底色、
>   加载屏门板与内光。**紫不进控件**（不做紫色按钮、不做紫色文字）。
> - **银**（`--basic` / `--signal`）负责骨架：六边形网格线、分隔线、控件描边、等宽铭牌。
> - **金**（`--accent`）只出现在"被点亮"的位置：当前项、完整标记、关键读数、焦点环、
>   hover 态、站徽。**任何一屏里金色都应是最少的那种颜色。**
> - **紫不能做成霓虹**：饱和紫只允许出现在 ≤ 1px 的描边、低不透明度的柔光与渐变里；
>   大面积紫色必须是"墨"（明度 ≤ 22%）。禁止 `#7B2FF7` 一类的荧光紫。

### 2.4 舰队色（只在舰队页生效）

| 令牌 | 值 | 舰队 |
| --- | --- | --- |
| `--fleet-research` | `#3DAEFF` | 科研与管理舰队 |
| `--fleet-industry` | `#DBA400` | 工业与收集舰队 |
| `--fleet-defense` | `#E0544C` | 主防御舰队 |

**落点规则（v3 修正：三色必须"静态生效"）**

1. **静止态**就要看得出编成归属：卡片左侧 2px 编成色条 + 右上角序号用编成色（62%），
   卡面其余部分是半透明平涂 + 银结构。
2. **hover / 键盘聚焦**：整卡按编成色点亮 —— 描边、平涂底色（10% 编成色）、标题、
   `进入编成 ›` 全部转编成色；同时 `fleet.js` 把**整页主题色**
   （星野 / 极光 / 激活区 / 顶栏 / 选区）平滑换成同一个编成色（320ms）。
3. 舰队色**不外溢**：其它页面不得出现 `--fleet-*`；舰队页内部也不得用它替代金色去做"已收录 / 焦点"。
4. 主防御 `#E0544C` 与错误红 `--alert #FF7A6B` 不是一件事：前者是编成色，后者只表示失败。

| `--line-1` | `rgba(192,192,192,0.09)` | 分隔线、卡片描边 |
| `--line-2` | `rgba(192,192,192,0.16)` | 控件描边、悬停描边 |
| `--line-3` | `rgba(204,200,224,0.28)` | 聚焦、强调结构线 |
| `--line-accent` | `rgba(255,215,0,0.42)` | 金色结构线（眉标、选中） |
| `--line-signal` | `rgba(192,192,192,0.28)` | 银结构线（占位、刻度） |
| `--line-tone` | `rgba(95,81,176,0.45)` | 紫结构线（加载屏取景框、"门内"结构） |
| `--grid-line` | `rgba(192,192,192,0.20)` | 星野六边形网格 |
| `--grid-dot` | `var(--accent)` | 网格中心点 |

**星野 / 六边形背景（`background.js`）**：天空三段 = `#0C0A1C → #0A0817 → #05040C`（= `--grad-sky`）；
六边形描边 `BASE_STROKE: #8B849C`（基本色银压暗一档）；激活区描边 / 柔光 / 极光取 `TONE = #3A3072`；
圆点 / 连线 / 金环 / 掠光 / 点击波纹取 `THEME = #FFD700`。
`setTone()` 只换紫（舰队页换编成色），**金色与银色不参与换色**。

## 三、字体与层级

### 3.1 字体栈（v3 未改）

```css
--font-sans: "Sarasa", "Sarasa Gothic SC", system-ui, "Segoe UI", sans-serif;   /* 全部标题与正文 */
--font-mono: "Sarasa Mono", ui-monospace, "Cascadia Mono", Consolas, monospace; /* 读数、编号、英文副题 */
```

- 只装 Regular / Bold 两个字面；`font-synthesis-weight: none`，**不用伪粗体**。
- 中文标题不加粗，靠**字号 + 字距 + 留白**分层；粗体只给正文里的关键词。
- 拉丁文（英文副题、状态、代号）一律等宽 + 大写 + 宽字距（`.10–.26em`），这是"仪器铭牌"的语汇。
- `font-display: block` 不变：加载屏等字体；内容页由 `sss-switch` 盖住字体解码窗口。

### 3.2 层级（v3 未改）

| 角色 | 令牌 | 字体 | 字号 | 字距 | 行高 |
| --- | --- | --- | --- | --- | --- |
| 首页主标题 | `--fs-display` | sans 400 | `clamp(36px, 5vw, 62px)`（窄屏 `clamp(24px, 7vw, 48px)`） | `.10em` | 1.08 |
| 页面标题 | `--fs-h1` | sans 400 | `clamp(24px, 3.2vw, 30px)` | `.20em` | 1.3 |
| 区块 / 卡片标题 | `--fs-h2` | sans 400 | 17px | `.08em` | 1.5 |
| 小标题 | `--fs-h3` | sans 700 | 15px | `.06em` | 1.6 |
| 导语 | `--fs-lead` | sans 400 | 15px | `.02em` | 1.95 |
| 正文 | `--fs-body` | sans 400 | 14px | `.01em` | 1.90 |
| 界面控件 | `--fs-small` | sans 400 | 13px | `.06em` | 1.4 |
| 元信息 / 副题 | `--fs-meta` | sans / mono | 12px | `.10em` | 1.7 |
| 眉标 / 状态 | `--fs-label` | **mono** | 10px | `.26em` | 1.4 |
| 四角读数 | `--fs-micro` | **mono** | 9px | `.24em` | 1.2 |

### 3.3 页面头部语法（所有页面必须一致）

```html
<p class="page-eyebrow"><span class="page-eyebrow__id">ARCHIVE</span></p>
<h1>档案</h1>
<p class="page-sub">Archives</p>
<p class="page-lead">……一句世界观内的导语……</p>
```

- 眉标：等宽、**银**（`--signal`），只保留英文标识，后面接一条 1px 金色渐变横线。
  **不再写 `// 04` 一类的编号，也不写「本地缓存 · 已建档」一类的状态尾注**——
  这些信息要么没有意义，要么属于页面正文，不放在页头。
- 标题：**冷白**（不是金色）。金色留给眉标短横线、完整标记与关键读数。
- 英文副题：等宽、`--fg-3`、大写宽字距。
- 导语：正文色，最多两行；加载屏式"读数"语气，不写实现说明。
- 顶栏菜单（v5.1）：字号与正文同级（`--fs-body` 14px），不再用 `--fs-small` 降一档；
  当前项仍只靠底部金线 + 冷白区分。

### 3.4 面包屑（v4 修正）

**档案页不从「首页」起算。** 档案区自成一个系统，路径以"档案"为最上层：

| 页面 | 面包屑 |
| --- | --- |
| `archive/index.html`（总览） | `档案`（单层） |
| `archive/organization/index.html` | `档案 / 组织档案` |
| `archive/organization/cam.html` | `档案 / 组织档案 / 管理成员议会` |
| 其他档案子页 | `档案 / X` |

**两条硬规则：**

1. **相对位置恒定**：每一层在所有页面里都从同一条 x 轴起算，"档案"永远落在同一位置。
   总览页不得用装饰线 / 缩进 / 图标把当前层推开（`.crumb--root` 不再加 `::before`）。
2. **字体恒定**：字族、字号、字距、行高在所有页面完全一致；当前层**只用字重加粗**
   （`font-weight:700`）与亮一档的颜色区分，不改字号、不改字体族。

结构见 `global.css` 的 `.crumb` / `.crumb--root`。总览页只有一层是**正常状态**，
不要为了"凑两级"再补一个「首页」或「本地缓存」。

## 四、组件规则

### 4.1 面板 / 卡片（v6 扁平化）

```css
background: var(--surface-card);          /* rgba(18,14,36,.58) 半透明平涂 */
border: 1px solid var(--line-1);
border-radius: var(--radius-panel);       /* 12px，全站卡片统一 */
box-shadow: none;                         /* 不用投影 */
backdrop-filter: blur(var(--blur-ui));    /* 2px，全站唯一一档 */
```

- **不做液态玻璃**：卡片不用渐变、不用顶部高光、不用大投影；星野从半透明卡片里透出来
  就是“投影在空气里”的效果。
- 可点击整卡：hover / `focus-visible` **只换描边、底色、文字颜色，不做位移、不加阴影**。
- 卡片左上角可加一枚 `INDEX` 序号（等宽、银、`09`），由 CSS counter 生成，不写进文案。
- 卡片内部间距 24–28px；标题与英文副题之间 8px；描述与底部动作之间 `margin-top:auto`。
- **文件档案的 `.md` 正文（v4）**：直接渲染在当前档案面板里，不再套第二层「纸面」
  （`.doc-sheet`）或「预览」框；纯文本不需要“预览原件”。其它载体（图 / 音 / 视频）
  仍用取景框 / 播放条，但取景框是**屏幕**、不是第二块面板。
- 舰队卡是唯一例外：左侧 2px 编成色条（见 §2.4）。

### 4.2 按钮 / 输入框

- 高 44px（触控），内边距 `10px 20px`，圆角 `--radius-control`（3px，直角感）。
- 默认：银雾底（`--ctl-bg`）+ `--line-2` 描边 + `--fg-1` 字；**金色只在 hover / 聚焦 / 选中出现**。
- hover 用 `--grad-btn-hover`（金从上往下渗下来），不是整块变成金色底。
- 标签用等宽大写 + 字距，例如 `ENTER`、`复制`。禁止胶囊按钮。
- 焦点环：`outline: 2px solid var(--line-accent); outline-offset: 2px`。

### 4.3 状态点（"通电 / 已收录"）

7px 方块、`border-radius:1px`、金色实心 + 金色柔光；未收录 / 离线用**空心银方框**。
加载屏阶段、Toast 统一用它。

### 4.4 读数（readout）

等宽、`--fg-4`、字距 `.14em`、`font-variant-numeric: tabular-nums`。
形式：`LABEL // VALUE`，分隔符 `//` 用金色 40% 不透明度。读数不做大，不写解释句。

### 4.5 圆角结论（v3 复核：保持不变）

| 层级 | 值 | 结论 |
| --- | --- | --- |
| 控件（按钮 / 输入 / 标签 / 复选框） | **3px** | 保留。直角感是"仪器面板"的语汇，改成 8/16px 会立刻变成"卡片 App" |
| 小标记（状态点 / 序号底 / 开关滑块） | **1–2px** | 保留（刻意近乎直角） |
| 面板 / 卡片 / 弹层 / 占位槽 | **12px** | 保留。12px 足够暗示"一块面板"，又不至于圆润到与 3px 控件冲突 |

**不引入中间档（6–10px）**：两档之外再加一档，界面上就会出现"三种圆角"，失去一致性。
真正需要视觉分层时用**描边 + 阴影 + 紫内光**，不要靠圆角。

### 4.6 动效结论（v3 复核：收敛，不再有过冲）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 时长 | `--dur-fast 140ms` / `--dur 220ms` / `--dur-slow 420ms` | 三档，够用；不新增档位 |
| 主题 / 编成换色 | `--dur-swap 320ms` | 整页氛围换色专用（`fleet.js` 同步），比普通过渡慢一档 |
| 缓动 | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 快出慢收；`--ease-out` 给"飞回 / 复位" |
| 位移 | ≤ 8px（淡入 0→8px） | 加载屏开门、页面切换除外（那是"门"，本来就该大位移） |
| 禁止 | 弹跳、过冲回弹、旋转卡片、视差大位移 | v3 修掉了公告弹层的 `cubic-bezier(.2,.9,.3,1.2)` 过冲 |

`prefers-reduced-motion: reduce` 下全部给终态（位移与时长一起抹掉，不能只抹时长）。

### 4.7 渐变结论（v6：卡片不再用渐变）

**卡片 / 面板一律平涂**（`--surface-card`），不做玻璃渐变、顶部高光、投影；
`--grad-panel` / `--grad-panel-in` / `--grad-lift` 保留变量名，但值已经是同一块平涂。

| 令牌 | 用途 | 形制 |
| --- | --- | --- |
| `--surface-card` | 所有面板 / 卡片 / 弹层 | 半透明紫墨平涂（alpha 0.58） |
| `--surface-card-hover` | 可点卡片 hover | 同色更亮一档（alpha 0.66） |
| `--grad-nav` | 手机展开的整屏导航面板 | 近实心紫墨（星野不透字） |
| `--grad-btn-hover` | 按钮 hover | 金 14% → 金 5%（渗下来，不是整块金） |
| `--grad-hatch` | 目录占位卡的 45° 斜纹 | 银 4.5%，1px / 9px |
| `--grad-sky` | 星野天空三段（与 `background.js` 同色） | 紫墨渐变 |

规则：卡片不写 `linear-gradient`；页面也不要再写渐变的字面色值。
显式禁止：彩虹 / 多色相渐变、金属拉丝、液态玻璃。

## 五、目录占位（仅未归类档案）

> **v7：全站移除 `CATALOG // …` 状态条。** 目录不再报状态、不报数量；
> 页面正文已经说明“数据损坏 / 本地缓存”，状态条是重复信息，不要加回来。

### 5.1 默认：什么都不显示

- 目录 / 列表 / 分类页照常渲染条目，**不插占位卡、不加状态条、不显示读数**。
- 预留空间靠数据与容器本身保持可扩展（数据驱动列表、直接追加卡片 / 数据），
  不需要画一张“待收录”的假卡片。
- 不要为了“说明情况”再加一条目录状态条；损坏 / 离线由页面导语说明。

### 5.2 唯一例外：未归类档案

「未归类档案」是世界观里的本地文件集合，会持续有新文件归档，所以保留一张
`VACANT SLOT / 待收录`。容器必须**显式**写 `data-catalog-slot`：

```html
<div class="document-list__scroll" data-catalog data-catalog-kind="list"
     data-catalog-unit="项" data-catalog-slot
     data-catalog-slot-desc="本地文件尚未归类归档"></div>
```

其它任何页面都不得使用 `data-catalog-slot`；占位卡不可点、不参与 hover、不写进计数。

### 5.3 严禁

- 在全站任何目录页重新加回 `CATALOG` 状态条 / 状态读数。
- 在未归类档案之外插 `VACANT SLOT` 占位卡。
- 把「数据损坏」写成「未收录 / 待补录 / 待解封」——那是把损坏说成圣域的收录缺口。
- 在占位里写实现说明（“点击后会……”）。只写世界内的状态。

### 5.4 落地方式

- 通用组件：`assets/css/catalog.css` + `assets/js/catalog.js`。
- `data-catalog` 只是钩子；没有 `data-catalog-slot` 时**没有任何视觉输出**。
- 新目录页 = 复制页头语法 + 正常条目；不要另造一种“未开放 / 未缓存”样式。
  只有「未归类档案」这类会持续增长的本地集合，才加 `data-catalog-slot`。

## 六、页面骨架与加载屏

- 每页 `<head>` 顺序：`tokens.css` → `boot.css` → `global.css` → `catalog.css`（目录页）→ 页面样式。
- 加载屏（紫金化，v3）：
  - 门板 `--ink-1000`，靠中缝的一端升到暗紫 `#0E0A22`（"被中缝金光照亮的紫墨"）。
  - 细网格：银 5% + 中心一层 `--tone` 40% 的紫光（门内是圣域，门外是深空）。
  - 徽记本体用紫（`--tone` 34%），外圈是**银色**正圆，进度弧 / 进度块 / 阶段完成 / 百分比是**金**。
  - 取景框用紫结构线 `--line-tone`；角标、刻度、斜纹、四角读数一律银。
  - 标题 sans + 一层极淡金辉光 + 一层紫雾，不再整屏只用等宽。
  - **终端身份**：版本 `AstraOS ver.7.0.4-5500430`、权限 `SXM` 只在
    `assets/js/boot.js` 的 `SSS_TERMINAL` 定义一次；加载屏左上（版本）与右上（AUTH）
    以及页面上所有 `[data-terminal="os|version|full|auth"]` 都读它。权限系统以后重做时只改这里。
- 404 / 离线页：同一块半透明平涂面板（`--surface-card`）+ 同一套页头层级；
  错误码是整页唯一的金色读数。
- **世界观状态不常驻**（v5）：终端不再在顶栏挂 `LINK // OFFLINE`，也不给星图入口贴
  `OFFLINE` 标记。星图系统是**独立系统**，离线与否由它自己的 `Offline Mode` 表达；
  主站只负责本地档案，损坏用「数据损坏 / 拒绝访问」的页面内文案说明，不做全局状态灯。
- **不再使用渐隐遮罩（v4）**：档案滚动区的内容上下边缘保持清晰，不挂 `mask-image`；
  滚动只靠滚动条与视口框。
- 页脚：全站同一段文案，等宽 11px、`--fg-4`、上边 1px `--line-1`。

### 6.1 星图页是刻意隔离的（v3 不变）

`tool/starmap/**` 为沉浸式星图，**刻意不做成主站风格**：它有独立的 `assets/css/starmap/index.css`、
`assets/js/starmap.js`、`assets/js/starmap-bg.js`（覆盖 `SSS_BG` 成更安静的坐标纸底）。
v3 只允许它"吃到"全局令牌的墨色与金色（因为 `tokens.css` 是全局的），
**不要求、也不进行**任何页面级重构。改动主站时不要顺手去改星图。

## 七、令牌清单（实现位置）

`assets/css/tokens.css` 分八组：
1. 墨色阶 / 表面　2. 语义色与舰队色　3. 线 / 网格　4. 字体与层级
5. 间距 / 圆角　6. 高度 / 动效 / 层级　7. 渐变 / 发光　8. 旧令牌别名

同时把旧的 `--ctl-*` **别名**到新令牌上（历史样式表因此自动换色，不必逐条重写）：

```css
--ctl-bg:        rgba(var(--basic-rgb), 0.05);
--ctl-bg-strong: rgba(var(--accent-rgb), 0.12);
--ctl-border:    var(--line-2);
--ctl-border-hover: var(--accent);
--ctl-fg:        var(--fg-1);
--ctl-fg-dim:    var(--fg-3);
--ctl-fg-hover:  var(--accent-bright);
--ctl-radius:    3px;
--ctl-panel-radius: 12px;
--ctl-err:       var(--alert);
```

**新代码只写新令牌**；旧代码允许继续用 `--ctl-*`，但每次改动顺手迁到新令牌。
禁止在页面样式里写死金色 / 紫色 / 黑色字面量
（`#FFD700`、`#3A3072`、`rgba(255,215,0,…)` 等）——除了 `tokens.css` 与
`background.js` 的 `DEFAULTS`（画布拿不到 CSS 变量，必须在那里写一份，且与令牌同值）。
